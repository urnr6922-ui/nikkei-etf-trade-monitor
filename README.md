# 日経ETF Trade Monitor

1570（日経レバ）と1357（日経平均ベア2倍）をスマートフォンで確認する、ダークモードのテクニカル監視Webアプリです。

## 現在の実装
- 1570 / 1357 の切替
- 1分足 / 5分足 / 15分足 / 日足の切替UI
- ローソク足、出来高表示
- SMA20 / EMA20 / RSI14 / MACD / ボリンジャーバンド
- 買い候補 / 売り候補 / 中立の情報シグナル
- 指標の表示・非表示設定
- 自動更新ON/OFF UI、通知設定UI
- スマホ向けダークUIと固定ナビゲーション
- 投資助言ではないことを明示

## データについて
現在のチャートはUI検証用のデモデータです。実市場データとして扱わないでください。実運用では、利用規約・ライセンスを満たした認可済みの市場データ提供元をデータ層へ接続します。証券会社APIやExcel/VBAを前提にしない構成です。
